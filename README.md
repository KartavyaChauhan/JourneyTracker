JourneyTracker (Jetpack Compose Version)
📌 Overview
JourneyTracker is an Android application that helps users track their travel progress with multiple stops. This version is implemented using Jetpack Compose for a modern, declarative UI.

✨ Features
Track Travel Stops: Displays a list of stops with distance, visa requirements, and estimated travel time.
Progress Bar: Visual representation of journey completion.
Switch Units: Toggle between kilometers and miles.
Mark Next Stop: Update progress upon reaching a stop.
Distance & Time Tracking: Calculates distance between two locations and estimated travel time.
