# JourneyTracker (XML Version)

## 📌 Overview
JourneyTracker is an Android application that helps users track their travel progress with multiple stops. This version is implemented using **XML-based UI**.

## ✨ Features
- **Track Travel Stops**: Displays a list of stops with distance and visa requirements.
- **Progress Bar**: Visual representation of journey completion.
- **Switch Units**: Toggle between kilometers and miles.
- **Mark Next Stop**: Update progress upon reaching a stop.

## 🚀 How to Build & Run
1. **Clone the repository**
   ```sh
   git clone https://github.com/your-username/journeytracker-xml.git
   cd journeytracker-xml
   ```
2. **Open in Android Studio**
3. **Build APK**:
   - Go to `Build` → `Build APK(s)`
   - Find the APK in `app/build/outputs/apk/debug/app-debug.apk`

## 📦 APK Download
- You can download the latest APK from the `apks/` folder.
